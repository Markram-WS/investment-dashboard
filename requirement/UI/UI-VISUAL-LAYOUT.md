# 🎨 UI Visual Layout: Master Hub

เอกสารแม่บทสำหรับการออกแบบและจัดวางตำแหน่ง UI ของ Investment Dashboard ทั้งหมด. 
*ความงามแบบ Miro + ความฉลาดแบบ Anthropic.*

---

## 🧭 Master Navigation Map
เข้าถึงรายละเอียด Layout เชิงลึกของแต่ละหน้าจอ (พร้อมรองรับการขยายตัวในอนาคต):

1.  **[[UI-LAYOUT-OVERVIEW|📊 Overview Screen]]**: หน้าจอมอนิเตอร์พอร์ตโฟลิโอและสถานะความเสี่ยงรวม (Global Monitor).
2.  **[[UI-LAYOUT-TRANSACTIONS|📜 Transactions Screen]]**: ประวัติรายการโอนเงินและการเทรดแบบเบ็ดเสร็จ (Consolidated Ledger).
3.  **[[UI-LAYOUT-PORTFOLIO-ANALYTICS|⚙️ Portfolio Analytics & Grid]]**: ศูนย์บัญชาการจัดการออเดอร์และแผนกลยุทธ์ (Command Center).
4.  **[[UI-LAYOUT-CREATE-PORTFOLIO|➕ Create New Portfolio Modal]]**: หน้าจอนำเข้าและตั้งค่าพอร์ตใหม่ (Onboarding).

---

## 🛠️ Global Design Principles
- **Visual Foundation:** Miro Portfolio System (ดูรายละเอียดที่ [[design system/DESIGN|🎨 Design System]])
- **Style:** Anthropic Pastel (สะอาด, สบายตา, ข้อมูลแน่นแต่ไม่รก).
- **Core Palette:** 
    - `Canvas`: #ffffff (White)
    - `Primary`: #1c1c1e (Black Pill Style)
    - `Accents`: Vibrant Pastels (Yellow #ffd02f, Blue #4262ff, Coral #ff9999, Teal #0fbcb0).
- **Typography:** geometric sans (Roobert PRO / Inter) ตามที่ระบุในเอกสารดีไซน์.
